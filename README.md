# Whack a Cat

Keep Mr. Biscuits in the air. Don't let him near the plants.

**Play it:** https://darrinstern-KM.github.io/whack-a-cat/

## How to play

- **Tap the cat** to bonk it back into the air. Combos score more.
- **Tap a plant** and you lose 5 points.
- **Miss** and the cat walks over and pees on a plant. Whack it on the way to save the plant (+3).
- Two pees kill a plant. Lose all five and it's game over.

### Keyboard

| Key | What it does |
| --- | --- |
| `Space` / `↑` / `W` / `Enter` | Swat the cat. It only connects once the cat drops into the low "swat zone" (dashed line). |
| `←` `→` / `A` `D` | Hold while swatting to aim the cat left or right |
| `P` / `Esc` | Pause |
| `M` | Sound on/off |
| `Space` / `Enter` on the menu | Start or play again |

Works with mouse, touch or keyboard. It's a single `index.html` with no dependencies, so you can also just download it and open it in a browser.
